💰 Tip Calculator (Android)

A simple and user-friendly Android app to calculate tips. Built using Android Studio, this app helps users quickly determine how much tip to leave.

📱 Features
💵 Enter bill amount
📊 Select tip percentage (preset or custom)
⚡ Real-time calculation updates
🎯 Clean and intuitive UI
🛠️ Built With
Kotlin
Android Studio
XML (Layouts)
Android SDK
